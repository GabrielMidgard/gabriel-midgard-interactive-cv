# CV interactivo de Gabriel Vázquez Ruiz

Sitio web 2D con estética dark fantasy construido con React, TypeScript,
Vinext y Vite.

## Requisitos

- Windows 10 u 11, macOS o Linux.
- [Node.js 22 o posterior](https://nodejs.org/).
- Conexión a internet durante la primera instalación.

## Inicio rápido en Windows

1. Descomprime el archivo ZIP.
2. Abre la carpeta resultante.
3. Haz doble clic en `iniciar-windows.bat`.
4. Cuando aparezca la dirección local, normalmente
   `http://localhost:3000`, ábrela en tu navegador.

La primera ejecución puede tardar varios minutos mientras se descargan las
dependencias.

## Inicio desde una terminal

```bash
npm install
npm run dev
```

Para comprobar la versión de producción:

```bash
npm run build
npm run start
```

## Dónde editar

- `app/page.tsx`: textos, experiencia, habilidades y estructura.
- `app/globals.css`: colores, animaciones y diseño adaptable.
- `app/layout.tsx`: título y metadatos del sitio.
- `public/og.png`: ilustración principal y portada para redes.

Para detener el servidor, vuelve a la terminal y presiona `Ctrl + C`.
